Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Fix for KWin crashing on GTX 10-series and older GPUs (#30).** On Pascal and earlier GPUs, opening the
  Android window could crash a compositor running on the same GPU (KWin), with thousands of NVIDIA "Xid 13 ...
  TEX LAYOUT" errors in the kernel log. Android's screen buffer was allocated as plain row-by-row memory while its
  contents were laid out in NVIDIA's tiled format. The compositor read the tiles from row-by-row memory, and on
  these GPUs that is a fault. Buffers shared with the desktop are now allocated with the tiled format, as NVIDIA's
  own driver does. RTX 20-series and newer GPUs were not affected and behave the same as before.
- `tests/run-probe.sh` no longer turns away hosts with the closed kernel module. The probe itself checks whether
  buffer sharing works.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`. Updating from an earlier rc is the same
commands. Supported GPUs, drivers and known issues are in the
[README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
